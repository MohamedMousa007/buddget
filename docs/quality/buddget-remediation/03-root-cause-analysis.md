# Root-cause analysis

One row per issue. Detail, `path:line` evidence and the full diagnosis tables are in `findings/`. "Confirmed" means the code that does it was read, or live data shows it. "Hypothesis" means plausible and not yet proven; the last column says what would prove it.

All 28 symptoms exist at `origin/main` and in the store builds (iOS 146, Android vc180). No unmerged branch fixes any of them.

Live data used below was read on 2026-11-20 with count-only queries.

## Where the brief's assumptions were wrong
1. Jobs 10 and 12 are not scheduled jobs.
2. PayTabs is not in the code; there is no web checkout to cancel.
3. The stay offer is merged and shipped (iOS 146), not pending.
4. "Profile completion" is the setup checklist.
5. There is no "Privacy & Data" screen to move biometrics to.
6. There is no invite landing page.
7. Account pickers elsewhere are not dropdowns.
8. "Conversation too long" is a cost meter; the model's context is never close to full.
9. The streak strip is a calendar, so "starts at zero" needs a design decision, not a bug fix.
