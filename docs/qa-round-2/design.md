## Critique (hierarchy / states / overflow)
- Hierarchy: consistent teal-primary CTA via cta/cta-block; Flow band + HeroBand siblings read well. Weak spots: three sheet-title styles (16/18px, h3/h2), two Close icon sizes.
- Empty/loading/error states are inconsistent: EmptyState primitive in 6 screens, 6 bespoke empties; SkeletonList in 11 files; error states are mostly inline text (no shared ErrorState/retry primitive); Offline/SyncFailure/Prompt/Update banners are four components with separate chrome.
- Destructive: confirm dialog usage good (21 files); delete on sheets via DeleteGoalSheet (dedicated sheet) vs confirm() elsewhere, two patterns.
- Truncation: `truncate` used on titles (SheetTitleBar, HeroBand cells). Amount cells use `truncate whitespace-nowrap` (HeroBand value `h-6 truncate`), which silently clips large money values (e.g. EGP 1,234,567.89) with no title/tooltip; Arabic names rely on `text-end` on rows; physical `left/right` utilities (51) are tolerated because layout is forced LTR.
- Keyboard in forms: only 12 `<form>` elements, so Enter-to-submit is absent in most sheets; custom NumberPad replaces native keyboard for amounts (good) but hides the CTA while text fields are focused.
