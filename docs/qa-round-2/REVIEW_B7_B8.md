## High
1. X8 theme script -> `src/app/(app)/layout.tsx:133`. In App Router, `<Script strategy="beforeInteractive">` with inline children is NOT emitted as a blocking `<script>`; next/dist/client/script.js:285 renders `(self.__next_s=...).push([...])` and the client runtime executes it during hydration. Scenario: dark-theme user cold loads, light paint, then flip (FOUC regression; also on Capacitor). Fix: revert to the plain `<script nonce dangerouslySetInnerHTML>` (add an eslint-disable for @next/next/no-sync-scripts if that was the motive), or verify in built HTML that a blocking inline script precedes first paint.
2. F6 -> `src/lib/store/debouncedPersistStorage.ts:35-37` / `src/lib/auth/clearBudgetData.ts:30`. clearBudgetData removes `buddget-storage` straight from localStorage while a debounced write may be pending in the closure Map. Fix: export a `cancelPendingPersist()`/use `useFinanceStore.persist.clearStorage()` in clearBudgetData before removeItem, and flush-or-drop pending on SIGNED_OUT.
