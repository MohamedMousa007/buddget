## RED / YELLOW narrative
RED: the owner's page says logos need a licence, written permission or approval we lack (Microsoft, Google x2, Apple, Adobe, Zoom*, Canva, NordVPN, Surfshark, Claude, AWS, GoDaddy, Cloudflare, DigitalOcean). Most still permit plain-text name use, so show text/initials. *Zoom and GoDaddy rest on search summaries.

YELLOW: no explicit prohibition found, or page unreadable (1Password, ExpressVPN, Proton, Perplexity, Namecheap, Grammarly, Bitwarden, ChatGPT, Midjourney, Notion), or conditional permission (Dropbox, Evernote, Slack, GitHub). Defensible as nominative use but residual risk; keep logo unmodified, subordinate, with a disclaimer.

GREEN: Figma only (identification allowed if truthful and unmodified).
