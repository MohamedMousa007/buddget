## Flags
- hbo_max.svg: HBO mark, not HBO Max. fortnite_crew.svg: Epic Games mark. microsoft_365.svg: older Office mark (simple-icons v9).
- mrsool.png is 200x200 (below 512px minimum); storytel.png 596x378; cursor.png 1024x1024.
- osn_plus, nyt: Commons search only returned wrong/old marks (OSN News, NYT 1890-1961); rejected.
- noon_one: Commons only returned an unrelated "Noon Against Putin" file; rejected.
- Rate-limited by Wikimedia (HTTP 429/HTML) at the end: google_one, starlink, instashop, webnovel downloads were rejected as HTML error pages and deleted.
