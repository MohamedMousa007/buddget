## Measured: monthly stats selector (repro/perf/statsTiming.test.ts.txt, TZ Africa/Cairo)
`computeMonthlyStats` over N expenses (no debts/savings, default budget), mean of 5 warm runs: 5k = 9-12 ms, 10k = 26 ms, 20k = 42-45 ms, 40k = 91 ms (a cold first pass showed 162 ms at 20k: JIT warm-up). Linear (about 2.2 ms per 1k); no O(n^2) in the hot path. `useMonthlyStats` is memoised by `computeMonthlyStatsShared` (one compute per identical input across hook instances) and `countedDebts/countedDebtPayments` return stable refs, so `useShallow` does not loop. Flow's `[...expenses].sort(localeCompare)` over all history costs about 30 ms at 20k, 70 ms at 50k: acceptable, not reported.
