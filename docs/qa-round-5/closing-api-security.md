- API-6: Fixed. `lib/auth/accountActive.ts` `isAccountActive` (Auth admin `getUserById`, `banned_until`/deleted, cached 60 s per user, fails open on Auth outage so a blip cannot drop SMS). Measured cost: one GoTrue admin call per user per minute per instance (not per SMS), instead of the verified-identity round trip per call. Applied to `resolveSmsCaller` (JWT and ingest-token paths) and, via `resolveActiveApiUserId`, to `push/register`, `push/send`, `sms/confirm|undo|setup-token`. `devices/[id]` DELETE: sessions are not recorded per device, and `auth.admin.signOut` is per JWT or global (would log out the phone in the user's hand), so it revokes everything device-scoped (SMS ingest tokens, push tokens, biometric binding, trusted-device row) and the route comment documents why. Tests: `accountActive.test.ts`, `resolveSmsUser.test.ts`, `resolveApiUser.test.ts`, existing removedDevice tests.
- API-9: Fixed.
