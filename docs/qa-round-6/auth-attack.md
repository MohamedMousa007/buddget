# QA Round 6: auth-attack (prefix AUT)

Covered: all 97 `src/app/api/**/route.ts` x every exported method with an anonymous forged request (executed), user A against user B on the user-bound routes (executed), forged/old JWTs against the real resolver (executed), `proxy.ts`, `next.config.ts` headers, CSP builder, native CORS, cron/webhook secret checks, cookies, admin guard/session/step-up/staff/users/financial/export/sms handlers, and the live database (RLS, column grants, triggers, SECURITY DEFINER RPCs, advisors, 2FA gate state). NOT covered: live HTTP against a deployed host, Auth dashboard settings (email-change confirmation, OTP expiry and verify rate limits, signup confirmation, JWT lifetime), bodies of `admin/emails|plans|platform|loyalty|crashes|ai/cost`, `receipt/scan` and `voice/transcribe` bodies, `sms/parse` beyond auth/validation (1.6k lines, ReDoS path read).

Repros: `docs/qa-round-6/repro/auth-attack/{matrix.test.ts.txt, attacks.test.ts.txt, stubs.ts.txt}` (119 tests, all pass; the passing tests are the clean evidence, the AUT-4/7/8/9 tests assert the defect). Copy to `src/__qa6__/auth-attack/` as `*.test.ts` to run.
