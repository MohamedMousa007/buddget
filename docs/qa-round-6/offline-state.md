## SUP-3 assessment (service worker)

Generated `public/sw.js` (next-pwa 5.6, Workbox 6) has two catch-all runtime rules with `NetworkFirst`, `networkTimeoutSeconds:10`, 24 h expiry: cache `apis` (same-origin `/api/*` except `/api/auth/*`, 16 entries) and cache `others` (every same-origin non-`/api` GET, 32 entries), plus `start-url` for `/`. Workbox keys by URL only, ignoring `Authorization`, so after account switch on a shared browser an offline or slow (>10 s) request for the same URL is answered with the previous account's JSON; nothing calls `caches.delete` on sign-out (`grep caches\. src` = 0 hits) and `clearBudgetData` touches localStorage only. Rule presence is Confirmed by reading `public/sw.js`; cross-user replay is Static (needs a browser). Native is unaffected (SW disabled when CAPACITOR). The finding stays P2 (agree with sec-supply); add the `others` cache to the fix list. Update flow: `skipWaiting:false`, so a new SW waits until the user accepts UpdateToast; not tested live.
