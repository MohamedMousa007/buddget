# QA Round 6: debts, BNPL/installments, credit cards, recurring generation (DEB)

Covered: debt payment/installment/recurring-plan maths, credit-card cycle and outstanding, subscription log-mode generator (24-month fake-clock sims), recurring savings scheduler, BNPL split plan, budget committed link (liveLinks), Cairo / New York / Riyadh runs. Not covered: live UI, `useSubscriptionDetector` false positives, two-device sync merges (reasoned statically), cron generation (there is none: see note), interest/snowball/avalanche (not implemented in the app: no APR, only `interestFree`; `gracePeriodDays` stored but unread).

Note: there is no recurring-expense generator. `recurringExpenses` is a planner template (monthly equivalent) used by budget facts; expense rows are only written by subscription `log` tracking / Mark paid, by user-confirmed debt reminders, by the savings scheduler, and by SMS.
