# QA Round 6: admin-site (prefix ADS)

Covered: admin RBAC matrix (every `guardAdmin` call vs nav and `REQUIRES`), IDOR on `[id]` routes, role escalation, audit completeness and immutability (route scan plus live trigger), destructive actions and step-up, PostgREST filter and CSV injection, users/leads/staff/platform/flags/support-ticket handlers, `support/submit`, `feedback`, `site/lead`, `site/event`, consent/cookies/third-party loading, account deletion coverage, legal pages (EN/AR), SEO (metadata, hreflang, sitemap, robots, JSON-LD), site a11y basics, store privacy docs vs manifests. NOT covered: no live browser run (coordinator owns the dev server), so contrast, focus order and CWV are unmeasured; admin email-template editor, loyalty/plans/ai-cost bodies and SMS template routes only skimmed; no repro tests written (all findings are source or live-DB reads).
