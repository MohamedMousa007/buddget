# QA Round 6: a11y-design (prefix A11)

Covered: design-system token compliance (hex/rgb/Tailwind colours, heights, z-index scale, safe-area), WCAG contrast of every CSS-variable token pair in light and dark, static a11y across `src/components` and `src/app` (names, roles, dialogs, focus, live regions, motion, titles/landmarks, text scaling, colour-only meaning, charts, timers), component-reuse drift, render tests for 18 primitives. NOT covered: admin and marketing-site (`/site`, `features/admin`) surfaces; any live rendering (no dev server, per brief). The repo has no jsdom/happy-dom/testing-library and the brief forbids adding dependencies, so the "render tests" are `renderToStaticMarkup` + `@xmldom/xmldom` assertions (role, accessible name, aria state, tabindex, native element) plus source-level contracts. Keyboard activation and focus return could not be executed; they are covered by reading `useDialogFocus`/`ModalShell` and by the live checks listed at the end.

Totals: 0 P0, 0 P1, 8 P2 (4 Confirmed, 4 Static), 12 P3 (3 Confirmed, 9 Static). Already reported elsewhere and not re-counted: FRM-7 (AmountField without a name). My scan finds 22 of 43 `<AmountField>` sites unnamed, consistent with FRM-7's 24.
